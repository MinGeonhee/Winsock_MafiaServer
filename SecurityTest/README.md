# 보안 테스트 (security/test 브랜치)

로컬 서버 · 우리 클라 전용 테스트 도구입니다.

## ① 정보 노출 : `scan_jobs.cpp`
클라 프로세스 메모리에서 "직업 7개 배열"(uint16, 1 ~ 7 순열)을 찾습니다. 치트엔진의 값 검색과 같은 방식입니다.

| 빌드 | 결과 |
|---|---|
| `2625b06` [취약 예시] 서버가 전원 직업을 보내고 클라는 화면에서만 가림 | 군인 클라 메모리에서 `1번=군인 2번=대통령 3번=탐정 4번=배신자 5번=영매 6번=마피아 7번=경호원` (실제 배치와 일치) |
| `464abca` [수정] 자기 직업만 전송 | 클라 7개 전부 "직업 배열을 찾지 못함" |

결론 : 화면에서 가리는 건 보안이 아님. 숨길 정보는 서버가 보내지 않는다.

## ② 패킷 변조 : `forge_packets.py`
정상 클라를 거치지 않고 조작한 패킷을 서버에 직접 보내고, 서버 로그의 `거부 [...] 이유`를 확인합니다.

| # | 조작 | 서버 로그 |
|---|---|---|
| 1 | 게임 시작 전 능력 사용 | 거부 [능력] 게임 중이 아님 |
| 2 | 시민이 마피아인 척 처치 | 거부 [능력] 직업 불일치 (패킷 직업 ≠ 실제 직업) |
| 3 | 구조체 길이 조작 (2바이트 뺌) | 거부 [능력] 직업별 구조체 길이 불일치 |
| 4 | 없는 직업 번호 99 | 거부 [능력] 직업별 구조체 길이 불일치 |
| 5 | 머리보다 짧은 패킷 | 거부 [능력] 패킷 길이가 머리보다 짧음 |
| 6 | 탐정 첫날 밤 조사 | 거부 [능력] 탐정은 첫날 밤 조사 불가 |
| 7 | 영매가 산 사람 직업 보기 | 거부 [능력] 영매는 죽은 사람만 |
| 8 | 군인이 능력 패킷 | 거부 [능력] 직업별 구조체 길이 불일치 |
| 9 | 범위 밖 대상 (자리 99) | 거부 [능력] 잘못된 대상 (범위 밖 · 빈자리) |
| 10 | 마피아가 자기 자리 / 같은 밤 두 번째 처치 | 거부 [능력] 마피아끼리 처치 불가 / 이번 밤 이미 사용 |
| 11 | 밤에 시민 채팅 | 거부 [채팅] 지금 단계엔 채팅 불가 |
| 12 | 밤에 투표 · 찬반 | 거부 [투표] 투표 거부 / 거부 [찬반] 찬반 거부 |
| 13 | 다른 방 사람이 이 방 번호로 채팅 | 거부 [채팅] 방에 없는 사람의 채팅 |
| 14 | 없는 방 번호로 투표 | 거부 [투표] 없는 방 |

결론 : 클라가 보내는 값은 믿지 않고, 누가 보냈는지는 연결 키로 · 할 수 있는지는 서버 상태로 매번 다시 판정한다.

## ③ 메모리 변조 탐지 : `NetLib/Public/Protected.h`
판정 값이 클라에 있는 게임(HP · 쿨타임)용. 값을 랜덤 키로 XOR해 저장하고 체크값을 따로 두어, 한쪽만 바뀌면 꺼낼 때 탐지합니다.
마피아는 판정 값이 전부 서버에 있어 클라에 쓸 곳이 없습니다(①②의 구조로 대비).
